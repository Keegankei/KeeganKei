<a id="keestashdock"></a>

### [KeeStashDock](https://github.com/Keegankei/KeeStashDock)

**A portable Windows dock for snippets, screenshots, OCR, and on-demand translation.**

| Capability | What it does |
|---|---|
| **Capture** | Capture and organize text and images. |
| **OCR & translation** | Extract text from screenshots and translate selections. |
| **Layouts** | Choose Classic (formerly Standard) or Spatial panels. |
| **Optional components** | Install OCR and offline translation components in the app. |

**Built with** `C#` · `.NET` · `WPF` · `SQLite`

**[Download](https://github.com/Keegankei/KeeStashDock/releases/latest)**
· [Source](https://github.com/Keegankei/KeeStashDock)
· [Documentation](https://github.com/Keegankei/KeeStashDock#readme)

<a id="easyeda-schematic-style"></a>

### [EasyEDA Schematic Style](https://github.com/Keegankei/easyeda-schematic-style)

**A reusable Codex skill for organizing and reviewing EasyEDA Professional schematics.**

| Capability | What it covers |
|---|---|
| **Presentation** | Functional blocks, local wiring, labels, and interface summaries. |
| **Style** | Follow a reference sheet or start with project defaults. |
| **Verification** | Keep edits scoped and compare electrical connections. |
| **Documentation** | Setup guidance in English and Simplified Chinese. |

**Format** `Instruction-only skill` · **License** `MIT`

**[Download ZIP](https://github.com/Keegankei/easyeda-schematic-style/releases/download/v1.0.0/easyeda-schematic-style-v1.0.0.zip)**
